## Requested decisions

1. **Scientific framing:** Is the distinction between operating-context fitting on all training rows and early-life fitting of sensor/model/calibration components clear enough?
2. **Contribution framing:** Are the scientific/empirical contributions adequately separated from the governance and reproducibility contribution?
3. **Operational interpretation:** Does the paired presentation of FAR, engine coverage, and conditional delay prevent over-reading any single proxy result?
4. **Terminology:** Are P0, P1/K=6, operating mode, endpoint, proxy-healthy, internal held-out, and the project-specific Gate 4 freeze understandable without repository context?
5. **Literature comparison:** Is the no-direct-ranking conclusion appropriately cautious, and are the native metrics/caveats sufficient?
6. **Attribution boundary:** Is it unambiguous that PCA contributions explain reconstruction error in normalized feature space rather than physical root cause?
7. **Submission direction:** Which venue or template should govern the next formatting pass?

## Scope guardrail for requested changes

Wording, organization, presentation, and venue formatting can be revised directly. New uncertainty intervals, alternative splits, new literature-derived numbers, official-test results, detector fusion, threshold changes, or any other scientific extension require a separately registered analysis and must not overwrite the first valid frozen result.
